Project Overview

In 1971 Thomas Schelling showed a cornerstone result of complex-systems science: even mild individual preferences about one's neighbours can produce strong collective segregation: no agent wants a segregated city, yet segregation emerges. This project studies a continuous-space variant of that model: 2,000 point agents of two types live in an open 100 × 100 domain, and an agent is "happy" only if at least K_MIN = 30 same-type neighbours sit within distance R = 10. Unhappy agents teleport to random locations until they find one that makes them happy.

The model is implemented twice, on purpose. A Fortran 95 reference implementation answers the forward question (what do these rules produce?) at maximum speed. A differentiable PyTorch twin answers the inverse questions (which parameters produce an observed outcome, and how sensitive is the outcome to them?) by letting gradients flow through the simulated dynamics. Agent-based models are classically hard to calibrate precisely because they are non-differentiable; re-expressing the same model with smooth relaxations is what unlocks that second family of questions.

Making an Agent-Based Model Differentiable

Three discrete elements kill gradients in the original formulation. Each is replaced by a smooth counterpart that converges to the discrete rule as the temperatures τ → 0 (verified numerically):

Element Discrete rule (Fortran) Smooth relaxation (PyTorch)
Neighbourhood 1[d ≤ R] (hard disk) σ((R − d)/τ_d) (sigmoid shell)
Happiness 1[n ≥ K_MIN] (Heaviside step) σ((n − K_MIN)/τ_h) (soft gate)
Kinetics random teleports until happy unhappiness-gated gradient ascent

In the twin, each unhappy agent ascends the gradient of its own soft same-type count, gated by its unhappiness, while happy agents stand still, exactly as in the discrete model. The drift is computed analytically so autodiff stays free for the outer derivatives with respect to K_MIN, R and τ. The trade-off is stated honestly: local drift is not global teleporting, so the twin is validated against the reference, not a bit-exact replica: both reach full happiness at reference density, with final hard segregation 0.59 (drift) vs 0.63 (teleports).

Result 1: Sensitivity Analysis Through the Dynamics

One backward pass through 100 unrolled simulation steps (N = 2,000, float64, gradient checkpointing) yields the exact derivative of the final segregation index with respect to every model parameter, numbers that a forward simulator can only approximate with noisy, costly finite-difference sweeps:

∂ segregation / ∂ K_MIN
+4.84 × 10⁻³

More demanding agents produce more segregation. Schelling's qualitative insight, computed as a number.

∂ segregation / ∂ R
−2.26 × 10⁻²

Larger neighbourhoods dilute the same-type share: wider "vision" reduces segregation.

The gradients are cross-validated against a central finite-difference convergence table: agreement to 3 × 10⁻⁶ relative error at δ = 10⁻⁵.

Result 2: Gradient-Based Calibration (Inverse Problem)

The defining demo: a simulation is run with a hidden tolerance threshold K* = 35, and only its segregation trajectory is observed. Starting from a deliberately wrong guess of 24, Adam recovers the hidden parameter by backpropagating a trajectory-matching loss through the entire 120-step unrolled simulation:

Figure 4: Recovery of the hidden threshold. 60 Adam iterations, final estimate 34.99, trajectory MSE 8.2 × 10⁻¹⁰.

Engineering Highlights

Cell-Linked Neighbour Search

The standard molecular-dynamics structure: an M × M grid with doubly linked per-cell lists gives O(1) insertion/removal, and a 3×3 block search that is provably exact because the cell size satisfies L/M ≥ R (asserted at startup).

Exact Incremental Bookkeeping

After each relocation only agents within R of the departure and arrival points are re-evaluated; a teleport cannot affect anyone else. The unhappy set is maintained exactly with an O(1) inverse-index map; the full run takes ~0.4 s.

Gradient Checkpointing

Backprop through T steps naively stores O(T·N²) pairwise activations, prohibitive at N = 2,000. Recomputing activations in the backward pass drops memory to O(N²) total at ~2× forward compute, with gradients verified identical.

Reproducible & Device-Agnostic

Seeded RNG on both engines: bit-identical Fortran metrics across runs, and PyTorch initial conditions drawn on CPU so the same seed gives the same configuration on CPU and GPU. Every result on this page was measured on a laptop CPU.
